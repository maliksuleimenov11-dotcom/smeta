# Смета за 5 минут
Ссылка на сайт :
https://maliksuleimenov11-dotcom.github.io/smeta/

Веб-приложение для быстрого составления сметы или коммерческого предложения и сохранения результата в PDF.

Приложение предназначено для предпринимателей, которые готовят КП клиентам, и офисных сотрудников, которые составляют сметы закупок или рассчитывают расходы для руководителя.

## Файлы приложения

- `index.html` — структура страницы: поля ввода, список позиций, итоговая сумма и кнопки.
- `styles.css` — оформление страницы, удобные размеры элементов и адаптация для телефона.
- `script.js` — добавление и обработка позиций, расчёт сумм и подготовка результата к сохранению в PDF.

Эти файлы будут созданы на следующих этапах. Сейчас в папке находятся только документация и правила работы.

## Как открыть

После создания файлов приложения откройте `index.html` двойным щелчком. Страница откроется в браузере, установка дополнительных программ не нужна.

## Как проверить

После реализации расчёта добавьте две позиции:

1. Количество — 2, цена — 15 000 ₸.
2. Количество — 1, цена — 8 000 ₸.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
